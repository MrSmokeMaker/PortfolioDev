Документация API & SDK

Простая интеграция с вашим бэкендом. Доступны официальные библиотеки для Node.js, Python и универсальный REST API.

index.ts 
import { NexusClient } from '@nexus-ai/sdk';

const client = new NexusClient({ apiKey: process.env.NEXUS_API_KEY });

// Запуск агентского сценария с валидацией результата
const response = await client.agents.run({
  prompt: 'Сформировать аналитическую сводку по выручке за Q3',
  tools: ['database_query', 'excel_export'],
  temperature: 0.2
});

console.log('Результат выполнения:', response.output);
console.log('Затрачено токенов:', response.usage.totalTokens);

Основные REST-эндпоинты

POST /v1/agents/run Синхронный запуск сценария с ожиданием ответа
GET /v1/agents/{task_id}/stream Потоковая трансляция логов выполнения (SSE)
DELETE /v1/agents/{task_id} Принудительная остановка фоновой задачи
