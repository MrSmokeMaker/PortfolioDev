# Alex Rivera // Developer & AI Vibe Coder Portfolio

Премиальное адаптивное портфолио разработчика и вайбкодера нового поколения.

## 🚀 Ключевые особенности

- **Vibe & Glassmorphism UI**: Палитра глубокого темного режима (`#060911`, `#0B0F17`), неоновые акценты (индиго, фиолетовый, циан), мягкие радиальные градиенты и эффект матового стекла (`backdrop-filter: blur(16px)`).
- **Клиентский роутинг (SPA)**: Бесшовное переключение вкладок (`Home`, `Projects`, `Stack`, `About`, `Contact`) без перезагрузки страницы с анимациями `Fade/Slide`.
- **Двухуровневая адаптивная навигация**:
  - **Desktop**: Фиксированный стеклянный Header со статусом активности (`🟢 Online & Building`).
  - **Mobile**: Плавающий нижний док (Floating Bottom Dock) с крупными touch-friendly иконками.
- **Интерактивные объекты**:
  - **Desktop**: 60 FPS Canvas Constellation (частицы, реагирующие на курсор мыши) и интерактивный мини-терминал с поддержкой команд (`help`, `skills`, `projects`, `whoami`, `clear`, `matrix`, `date` и др.).
  - **Mobile**: Легковесная анимированная карточка симуляции кода без лишней нагрузки на процессор и батарею устройства.
- **Bento Grid проектов**: Интерактивная галерея кейсов с фильтрацией по категориям (`Все`, `Web & SaaS`, `AI & Agents`, `GameDev & 3D`) и модальными окнами с архитектурным разбором и метриками.
- **Стек & Био**: Детальный арсенал технологий и манифест современного вайбкодинга (ИИ-оркестрация + надежная инженерная база).
- **GitHub Pages Ready**: Чистая архитектура, поддержка `.nojekyll`, отсутствие внешних тяжелых зависимостей.

## 📂 Структура проекта

```text
├── index.html            # Главный семантический файл приложения (HTML5, OpenGraph, ARIA)
├── .nojekyll             # Флаг для GitHub Pages (обход Jekyll)
├── css/
│   └── style.css         # Модульные стили, CSS переменные, Bento Grid, медиа-запросы
├── js/
│   ├── app.js            # SPA роутер, рендерер Bento Grid, модалки, тосты, формы
│   ├── terminal.js       # Интерактивный терминал с автокомплитом и историей
│   └── particles.js      # Оптимизированный Canvas Constellation движок
└── assets/
    └── favicon.svg       # Векторный фавикон в неоновом стиле
```

## 🛠 Локальный запуск

Проект не требует сложных сборщиков и запускается любым статическим веб-сервером:

```bash
# С помощью npx serve
npx serve .

# Или Python
python -m http.server 3000
```

Откройте в браузере: `http://localhost:3000`
